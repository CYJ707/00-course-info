## Q3 · Conceptual — the bias–variance decomposition

**(a) Sketch** squared bias, variance, training error, test error and the irreducible (Bayes)
error on one plot, against model flexibility.

- **Draw it by hand and upload a photograph.** A generated, plotted or copied figure earns no marks.
- Label both axes and all five curves.

**(b) Explain** why each of the five curves has the shape you drew — one short paragraph per curve.
**Most of the credit for Q3 is here.** Say, in particular, why the test error is U-shaped and why
the training error can fall below the irreducible error.
Squared Bias (Monotonically Decreasing):

As model flexibility increases, the model can fit more complex patterns in the data, thereby reducing systematic errors (assumptions made by a model to make a target function easier to learn).

Variance (Monotonically Increasing):

Higher flexibility allows the model to adapt more closely to the training dataset. Consequently, small changes in the training data produce large variations in the estimated function.

Training Error (Monotonically Decreasing):

More flexible models can overfit and closely follow the training points, continually reducing the residual sum of squares on the training set toward zero.

Test Error (U-shaped Curve):

Initially, as flexibility increases, the substantial reduction in bias outweighs the small increase in variance, causing the test error to decrease. However, beyond an optimal point, the rapid increase in variance dominates (overfitting), driving the test error back up.

Bayes / Irreducible Error (Horizontal Line):

This represents the baseline noise inherent in the true data-generating process (ϵ). It is independent of model choice or flexibility, remaining constant across all levels of flexibility.

## Q7 · By hand — K-nearest neighbours

The exercise gives six observations with three predictors and a class label, and a test point at
X₁ = X₂ = X₃ = 0.

---

#### (a) Compute the Euclidean distance from each observation to the test point. Show the working.

The test point is $X_0 = (0, 0, 0)$. The Euclidean distance formula is:

$$d(X_i, X_0) = \sqrt{(X_{i1} - 0)^2 + (X_{i2} - 0)^2 + (X_{i3} - 0)^2} = \sqrt{X_{i1}^2 + X_{i2}^2 + X_{i3}^2}$$

* **Obs. 1:** $\sqrt{0^2 + 3^2 + 0^2} = \sqrt{9} = 3$
* **Obs. 2:** $\sqrt{2^2 + 0^2 + 0^2} = \sqrt{4} = 2$
* **Obs. 3:** $\sqrt{0^2 + 1^2 + 3^2} = \sqrt{10} \approx 3.162$
* **Obs. 4:** $\sqrt{0^2 + 1^2 + 2^2} = \sqrt{5} \approx 2.236$
* **Obs. 5:** $\sqrt{(-1)^2 + 0^2 + 1^2} = \sqrt{2} \approx 1.414$
* **Obs. 6:** $\sqrt{1^2 + 1^2 + 1^2} = \sqrt{3} \approx 1.732$

---

#### (b) Predict the class with K = 1, and say which observation decides it.

* **Prediction:** Green
* **Decision Observation:** Observation 5
* **Working / Justification:**  
  For $K = 1$, we look for the single nearest neighbour with the smallest distance. **Observation 5** has the smallest distance ($\sqrt{2} \approx 1.414$) to the test point, and its class label is **Green**. Therefore, Observation 5 decides the prediction, which is Green.

---

#### (c) Predict the class with K = 3, and say which observations decide it.

* **Prediction:** Red
* **Decision Observations:** Observation 5, Observation 6, and Observation 2
* **Working / Justification:**  
  For $K = 3$, we select the 3 observations with the smallest distances:
  1. **Obs. 5** (Distance = $\sqrt{2} \approx 1.414$, Class = Green)
  2. **Obs. 6** (Distance = $\sqrt{3} \approx 1.732$, Class = Red)
  3. **Obs. 2** (Distance = $2$, Class = Red)

  By majority vote among these 3 deciding observations, we have 2 Red and 1 Green. Since Red is the majority, the predicted class is **Red**.

---

#### (d) If the Bayes decision boundary is highly non-linear, should the best K be large or small? Justify.

* **Answer:** Small $K$
* **Justification:**  
  A **small $K$** provides high model flexibility, allowing the decision boundary to be highly non-linear and complex to fit the true underlying boundary. Conversely, a large $K$ provides a smoother, nearly linear boundary with lower flexibility, which would fail to capture a highly non-linear boundary.
